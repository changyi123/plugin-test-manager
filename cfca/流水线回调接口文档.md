# 测试管理平台 - 自动化执行结果回调接口

## 接口信息

- **接口地址**: 暂时留白，本周提供
- **请求方式**: `POST`
- **Content-Type**: `application/json`

## 鉴权方式

使用以下请求头进行鉴权：
- `X-Parse-Application-Id`: osc  (租户key)
- `X-Parse-Session-Token`: a:ug9yu2qzh84rl102az3usdex   (写死即可)

## 请求参数

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| buildId | string | 是 | 执行唯一ID（触发时由pipe平台生成） |
| status | string | 是 | 执行状态：completed/failed |
| logFile | string | 否 | 日志文件URL |
| reportFile | string | 否 | 测试报告文件URL（Excel格式） |

## 请求示例

```json
{
  "buildId": "exec_20240115_143052_8f3a",
  "status": "completed",
  "startTime": "2024-01-15T14:30:52Z",
  "endTime": "2024-01-15T14:35:47Z",
  "logFile": "https://storage.example.com/logs/exec_20240115_143052_8f3a.txt",
  "reportFile": "https://storage.example.com/reports/exec_20240115_143052_8f3a.xlsx"
}
```

## CURL示例

```bash
curl --location 'http://test-manager-server:8467/apps/api/v1/DCE3/apps/test_manager/environments/production/webtriggers/pipeAutomationCallback' \
--header 'X-Parse-Application-Id: osc' \
--header 'X-Parse-Session-Token: a:xxxxxxxxxxxxxxxxxxxxxx' \
--header 'Content-Type: application/json' \
--header 'Accept-Encoding: gzip' \
--data '{
  "buildId": "exec_20240115_143052_8f3a",
  "status": "completed",
  "logFile": "https://storage.example.com/logs/exec_20240115_143052_8f3a.txt",
  "reportFile": "https://storage.example.com/reports/exec_20240115_143052_8f3a.xlsx"
}'
```

## 响应格式

```json
{
  "success":true,
  "code":200,
  "data":{
    //other
  }
}
```
