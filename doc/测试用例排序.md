
# 测试管理事项导入和查询排序

## 说明
1. 导入按照 excel 的顺序导入
2. 批量添加测试用例也按照导入的顺序
3. 新建测试执行的顺序和测试用例的顺序保持一致

## 涉及改动地方
1. 在 Test 表中增加 sortIndex 字段辅助排序
2. 测试用例，测试执行类型所有涉及顺序查询的接口（asc sortIndex）涉及的接口：
    - getTestEntitiesByRelationWithOrder
    - getTestEntitiesByQuery
    - getTestEntities
3. 测试用例导入时，批量创建测试用例时增加 sortIndex 字段辅助排序
    ```javaScript
        // 创建时间优先级 > 排序索引优先级
        Math.floor(Date.now() / 1000) * 10e5 + index
    ```
4. 创建测试执行时需要将测试用例的 sortIndex 给复制到新生成的测试执行数据里
5. 测试用例创建的时候需要增加索引顺序，生成规则
    ```javaScript
        Math.floor(Date.now() / 1000) * 10e5
    ```
