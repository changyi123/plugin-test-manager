# 自动化队列统计和监控方案

## 🎯 目标

解决当前Webhook处理中的核心问题：
1. 不知道每次处理会产生多少测试用例
2. 处理过程中无法看到具体进度
3. 出问题时难以定位是哪个文件导致的
4. 日志过多，难以快速排查问题

## 📋 方案概述

**核心思路：在现有解析流程中插入统计，实现增量统计和实时监控**

- ✅ 复用现有解析逻辑，不重复调用
- ✅ 在关键节点插入统计代码
- ✅ 增量累加，实时更新进度
- ✅ 文件级别的精确追踪

### Phase 2: 在文件处理流程中插入统计

**位置**: `processFilesWithClosedLoop` 函数内部

```typescript
// 需要传入 queueId 参数
export function processFilesWithClosedLoop(diffData, config, historyMappings, queueId) {
  const decisions = [];
  
  for (let i = 0; i < diffData.length; i++) {
    const file = diffData[i];
    const startTime = Date.now();
    
    // 更新当前处理文件
    if (queueId) {
      await updateCurrentFileProgress(queueId, file.filename, i + 1);
    }
    
    // 现有的处理逻辑
    const decision = processFileDecision(file, config);
    decisions.push(decision);
    
    // 记录文件处理日志
    if (queueId) {
      await logFileProcessing(queueId, commitId, file.filename, decision, Date.now() - startTime);
    }
  }
  
  return decisions;
}
```

### Phase 3: 在用例生成中插入统计

**位置**: `processDecisionResults` 函数内部

```typescript
export async function processDecisionResults(fileDecisions, config, commitContext) {
  const operations = [];
  
  for (const decision of fileDecisions) {
    if (!decision.shouldProcess) continue;
    
    // 现有的操作生成逻辑
    const fileOperations = await generateOperationsForDecision(decision);
    operations.push(...fileOperations);
    
    // 插入用例数量统计
    if (commitContext.queueId && fileOperations.length > 0) {
      await updateCaseGenerationProgress(
        commitContext.queueId, 
        decision.fileName, 
        fileOperations
      );
    }
  }
  
  return operations;
}
```

### Phase 4: 在执行阶段插入结果统计

**位置**: `executeCaseOperations` 函数内部

```typescript
export async function executeCaseOperations(operations, workspaceKey, commitContext) {
  // 开始执行前更新状态
  if (commitContext.queueId) {
    await storage.entity('AutomationWebhookQueue').set(commitContext.queueId, {
      currentStep: 'executing_operations',
      pendingOperations: operations.length
    });

  const results = await batchExecute(operations);
  
  // 插入执行结果统计
  if (commitContext.queueId) {
    await updateExecutionProgress(commitContext.queueId, results);
  }
  
  return results;
}
```

## 🛠️ 统计函数实现

### 1. 更新当前文件进度

```typescript
async function updateCurrentFileProgress(queueId: string, fileName: string, processedCount: number) {
  await storage.entity('AutomationWebhookQueue').set(queueId, {
    processedFiles: processedCount,
    currentFile: fileName,
    currentStep: 'processing_file',
    lastUpdateTime: new Date()
  });
}
```

### 2. 记录文件处理日志

```typescript
async function logFileProcessing(
  queueId: string, 
  commitId: string,
  fileName: string, 
  decision: any,
  processingTime: number
) {
  await storage.entity('FileProcessingLog').add({
    queueId,
    commitId,
    fileName,
    shouldProcess: decision.shouldProcess,
    processingTime,
    timestamp: new Date(),
    errorMessage: decision.error || null
  });
}
```

### 3. 更新用例生成进度

```typescript
async function updateCaseGenerationProgress(queueId: string, fileName: string, operations: any[]) {
  const operationsCount = operations.length;
  const operationTypes = [...new Set(operations.map(op => op.operationType))];
  
  // 累加已识别的用例数
  const currentQueue = await storage.entity('AutomationWebhookQueue').get(queueId);
  await storage.entity('AutomationWebhookQueue').set(queueId, {
    identifiedCases: (currentQueue.identifiedCases || 0) + operationsCount,
    lastUpdateTime: new Date()
  });
  
  // 记录用例生成日志
  await storage.entity('CaseGenerationLog').add({
    queueId,
    fileName,
    operationsGenerated: operationsCount,
    operationTypes: JSON.stringify(operationTypes),
    timestamp: new Date()
  });
}
```

### 4. 更新执行结果统计

```typescript
async function updateExecutionProgress(queueId: string, results: ExecutionResults) {
  await storage.entity('AutomationWebhookQueue').set(queueId, {
    currentStep: 'completed',
    completedOperations: results.total,
    successfulCases: results.successful,
    failedCases: results.failed,
    skippedCases: results.skipped,
    lastUpdateTime: new Date()
  });
}
```
