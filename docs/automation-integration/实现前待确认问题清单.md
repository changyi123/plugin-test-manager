# 自动化用例同步 - 实现前待确认问题清单

## 一、业务逻辑相关

### 1.1 分支处理策略
- **问题**：是否只处理master分支的推送，还是所有分支都要处理？
- **影响**：决定是否需要分支过滤逻辑
- **建议**：只处理master和release分支

### 1.2 用例唯一性判断
- **问题**：当同一个`automationCaseId`出现在不同文件中时如何处理？
- **当前方案**：以最新提交的为准
- **需确认**：是否需要报错提醒用户存在重复？

### 1.3 配置文件缺失处理
- **问题**：`automation-test-map.json`不存在时的默认行为？
- **选项A**：跳过处理，不同步任何用例
- **选项B**：处理所有测试文件，用例创建到默认目录
- **需确认**：选择哪种方案？

### 1.4 用例删除策略
- **问题**：当代码中删除了测试函数，测试管理中的用例如何处理？
- **选项A**：物理删除用例
- **选项B**：标记为"已废弃"状态
- **选项C**：不做任何处理，保留用例
- **需确认**：采用哪种策略？

## 二、技术实现相关

### 2.1 Webhook鉴权
- **问题**：Webhook接收的Token验证方式？
- **当前方案**：使用固定的`X-Parse-Session-Token`
- **需确认**：
  - Token的具体值是什么？
  - 是否需要IP白名单？
  - 是否需要签名验证？

### 2.2 代码平台认证
- **问题**：Private-Token是否可以写死在代码中？
- **当前值**：`NmE4NjA2MDQtY2NmMC00MGJlLWE0NjYtMTk5MTMyMmQwM2Yw`
- **需确认**：
  - Token是否长期有效？
  - 是否需要定期更新机制？
  - 是否有权限范围限制？

### 2.3 用例创建接口
- **问题**：测试管理创建/更新用例的具体接口是什么？
- **需要明确**：
  - 接口路径
  - 请求参数格式
  - 必填字段和可选字段
  - 批量操作是否支持

### 2.4 测试管理目录映射
- **问题**：配置文件中的目录路径（如"全部用例库/用户认证"）如何映射到实际的目录ID？
- **需确认**：
  - 是否需要预先查询目录结构？
  - 目录不存在时是否自动创建？
  - 目录路径变更如何处理？

## 三、数据存储相关

### 3.1 自定义字段设计
- **问题**：`automationCaseId`存储在哪个自定义字段中？
- **需确认**：
  - 字段名称和类型
  - 是否需要创建新字段
  - 字段长度限制

### 3.2 执行记录关联
- **问题**：用例同步记录是否需要关联到具体的commit和提交人？
- **需确认**：
  - 是否记录每次同步的详细日志
  - 日志保留多久
  - 是否需要审计追踪

## 四、性能和限制

### 4.1 处理容量

### 4.2 并发控制

- **需确认**：

  - 是否需要加锁防止重复处理
  - 并发数限制

### 4.3 文件大小限制
- **问题**：单个测试文件的大小限制？
