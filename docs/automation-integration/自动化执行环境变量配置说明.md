# 自动化执行环境变量配置说明

## 概述
自动化执行功能支持通过环境变量配置JDK和Maven版本选项，便于不同客户环境的定制化配置。

## 环境变量配置

在Proxima平台的插件环境变量配置中，添加以下配置：

```json
{
  "AUTOMATION_JDK_VERSIONS": ["8"],
  "AUTOMATION_MAVEN_VERSIONS": ["3.6.3", "3.8.1", "3.9.0"]
}
```

### 配置项说明

1. **AUTOMATION_JDK_VERSIONS**
   - 类型：字符串数组
   - 默认值：`["8"]`
   - 说明：配置可选的JDK版本列表，值为版本号字符串（如"8", "11", "17"）
   - 示例：`["8", "11", "17"]`

2. **AUTOMATION_MAVEN_VERSIONS**
   - 类型：字符串数组
   - 默认值：`["3.6.3", "3.8.1", "3.9.0"]`
   - 说明：配置可选的Maven版本列表
   - 示例：`["3.6.3", "3.8.1", "3.9.0"]`

## 完整配置示例

与其他环境变量一起配置的完整示例：

```json
{
  "alias": {
    "repository": "分组"
  },
  "FEATURE_FLAGS": [
    "ENABLE_MINDER",
    "ENABLE_TEST_REPORT",
    "ENABLE_MORE_CONFIG",
    "ENABLE_TEST_REPORT_V2",
    "ENABLE_REPOSITORY_TABLE_STEP",
    "ENABLE_OFFLINE_TEST_REPORT"
  ],
  "AUTOMATION_JDK_VERSIONS": ["8"],
  "AUTOMATION_MAVEN_VERSIONS": ["3.6.3", "3.8.1", "3.9.0"]
}
```

## 使用说明

1. 如果未配置环境变量，系统将使用默认值
2. 配置的第一个版本将作为默认选中的版本
3. 对于JDK，建议优先使用版本8，因为大多数项目兼容JDK 8
4. Maven版本可根据项目实际需求进行配置

## 注意事项

- JDK版本值应该是字符串格式，如"8"而不是"1.8"
- 确保配置的版本在实际的Pipe执行环境中可用
- 修改环境变量后需要刷新页面才能生效
