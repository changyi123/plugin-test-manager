# 测试管理插件安装升级手册 v1

## 插件首次安装
1. 插件应用市场上传应用插件 ![上传插件](https://api2.mubu.com/v3/document_image/ee6ab171-7151-4cb1-9d22-c99b29147db6-5523808.jpg)
   1. 应用名称：测试管理
   2. 唯一标识：test_manager
   3. 应用版本：0.1
2. 插件数据初始化（事项类型，空间模板）
   1. 新建三个事项类型（测试用例，测试执行，测试计划）【需要三个事项的 itemType.key】![事项类型](https://api2.mubu.com/v3/document_image/ab7df307-87f5-440a-a684-0dfe7f8792d1-5523808.jpg)
   2. 使用原有或新建空间模板，空间模板至少需要包含上面三个事项类型对应的空间界面方案
   3. 应用市场测试管理插件关联按钮选择上面空间模板关联
   4. 使用被关联的空间模板创建空间【需要新建空间的 workspace.key】![创建空间](https://api2.mubu.com/v3/document_image/85e76348-32dc-4d5b-8ff7-fb9822ac9dd3-5523808.jpg)
   5. 插件中心关联测试管理模板
3. 插件脚本初始化
   1. 替换 SQL DML 脚本中的 uid（随机不重复即可）， itemType.key 和 workspace.key ，执行替换后的 SQL 脚本
   ```SQL
        INSERT INTO public."test_manager_TestConfig" ("objectId", "createdAt", "updatedAt", "workspaceKey", "itemTypeMap")
            VALUES ('uid', NULL, NULL, 'workspace.key', '{"TestPlan": "itemType.key(测试用例事项key)", "TestDetail": "itemType.key(测试计划事项key)", "TestExecution": "itemType.key(测试执行事项key)"}');
   ``` 
    > 上述 SQL 拼装后如下
   ```SQL
        INSERT INTO public."test_manager_TestConfig" ("objectId", "createdAt", "updatedAt", "workspaceKey", "itemTypeMap")
            VALUES ('XfASBoDPI1', NULL, NULL, 'test-test-test-012', '{"TestPlan": "test_test_000267", "TestDetail": "test_test_0002223", "TestExecution": "test_test_000212"}');
   ```
